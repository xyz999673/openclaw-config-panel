# Open Source Checklist

发布到 GitHub 前，建议逐项确认：

## 代码与仓库

- [ ] 补充 `LICENSE`
- [ ] 检查 README 的安装地址、域名、截图是否仍为你的私有环境
- [ ] 确认 `.gitignore` 已覆盖运行时状态文件
- [ ] 删除 `__pycache__/`、`*.pyc`

## 敏感信息

- [ ] 不包含真实 API key
- [ ] 不包含真实账号密码
- [ ] 不包含真实会话 token
- [ ] 不包含私有域名、私有 IP、内部路径说明

## 部署文档

- [ ] 说明 Python 版本要求
- [ ] 说明 `requests` 依赖
- [ ] 说明默认端口和 base path
- [ ] 说明需要已安装 `openclaw`

## 运行验证

- [ ] `python3 -m py_compile *.py`
- [ ] 安装脚本可执行
- [ ] 首次初始化可用
- [ ] 登录 / 登出可用
- [ ] Provider 保存 / 删除 / 刷新可用
- [ ] Agent 应用与全量应用可用

## 可选能力

如果你准备一并开源可选组件，再额外确认：

- [ ] Codex 控制台说明清楚是“可选”
- [ ] 导航页中的链接全部改成通用相对路径或占位说明
- [ ] Metapi / QingLong 等外部系统仅作为导航，不绑定私有部署细节
