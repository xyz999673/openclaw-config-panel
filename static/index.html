新增 Agent

只允许小写英文字母和下划线。新增时填写；已存在 Agent 不允许直接改 ID。
关闭后，这个 Agent 即使在支持的通道里也不能直接进入宿主机提权。
决定这个 Agent 进入宿主机后能执行到什么程度。
Web 管理台不是 Channels 管理的一部分，所以这里只保留 WebChat 来源控制；每行一个来源 ID，填写 * 代表该来源全开。
高风险：full + off 基本等于该 Agent 在允许来源下直接获得宿主机全权限。
仅在执行策略为 allowlist 时使用。建议优先放明确命令路径，不要一上来就写太宽的通配符。
